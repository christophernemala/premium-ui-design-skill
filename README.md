# premium-ui-design Skill

**Grok / agent skill** for building the strongest **clean, serene, pixel-perfect 3D SaaS websites** and luxurious UIs.

## What it does

- Full **spring physics motionography** (stiffness, damping, mass, bounce ≤ 0.2) with ready presets
- **Three.js / React Three Fiber** shader effects: liquid metal, soft glass, aurora, bloom, film grain, fresnel
- Cinematic movie-grade graphics + high-resolution **4K imagery**
- Prefer real **21st.dev** craft components (shaders, Liquid Metal Hero, glass, WebGL) — non-AI themes, fonts, and designs only
- Clean + serene aesthetic with generous whitespace, hairline borders, one strong idea per section
- Capable of full **SaaS product** interfaces as well as marketing sites

## Repository Structure

```
SKILL.md                          ← Core instructions (load this)
references/
  design-thinking.md              ← How to think + how to present the framework
  motion-guidelines.md            ← Complete spring physics explanation + presets
  threejs-shaders.md              ← Shader effects, post-processing pipeline, performance
  premium-palettes.md             ← Luxurious colour systems
  frameworks.md                   ← Exact libraries and stack order
```

## How to use

1. Place the folder in your agent skills directory (e.g. `.grok/skills/premium-ui-design/`)
2. The skill activates on triggers such as: UI design, SaaS product sites, 3D websites, cinematic motion, luxury interfaces, shaders, liquid metal, glass, dashboards, landing pages
3. Follow the workflow in `SKILL.md` and the detailed references
