# Premium UI Design

## Overview

Create clean, serene, pixel-perfect, luxurious websites and SaaS products. Combine high-resolution 4K imagery, cinematic motionography grounded in real spring physics, and carefully chosen Three.js / R3F shader effects. Always prefer real design-engineer craft from 21st.dev over generated aesthetics.

## Core Rules

- **Primary craft source**: 21st.dev components — shaders, Liquid Metal, Animated Shader Background, Horizon Hero, glass, aurora, volumetric beams, 3D cards, WebGL. Copy or adapt; never reinvent when a high-quality component already exists.
- **Stack**: Next.js + React + Tailwind + Framer Motion/Motion + React Three Fiber + drei + three.js. Tremor for SaaS charts.
- **Non-AI output**: Real fonts already in project or carefully chosen variable fonts, proven colour systems, craft components. No generic Inter + pastel gradients + soft-shadow cards.
- **Colour & Theme**: Deep near-black or soft off-white canvases, one strong accent (Linear lavender, Stripe indigo, soft gold), hairline borders, surface ladders. See premium-palettes.md.
- **Motionography & Physics**: Full spring physics (stiffness, damping, mass, bounce ≤ 0.2). Natural settle, serene timing. Detailed parameters and presets in motion-guidelines.md.
- **3D & Shaders**: Liquid metal, soft glass, aurora, bloom, film grain, fresnel. Start from 21st.dev, then refine with post-processing. Full guidance in threejs-shaders.md.
- **High-resolution imagery**: 4K / retina product renders and textures. Motionographic treatment via subtle parallax, shader distortion, or cinematic camera.
- **Clean & Serene**: Generous whitespace, one strong idea per section, pixel-level alignment, quiet confidence. Cinematic elements frame the product; they never obscure clarity.
- **SaaS capability**: The same system produces marketing sites and full product interfaces. Hierarchy, pricing, CTAs, and data remain primary.

## How to Think & How to Show the Framework

1. Tokens first (colour, type, space)
2. Layout system
3. Craft components (21st.dev + shadcn)
4. Motion system (spring presets + reduced motion)
5. 3D / shader layer + performance budget
6. High-res content and microcopy

See design-thinking.md for the full serene 3D SaaS approach.

## Workflow

1. Clarify product, luxury/serenity level, and cinematic intensity.
2. Lock colour tokens and type scale.
3. Pull 21st.dev shader / hero / glass / 3D components.
4. Apply spring-physics motion and selective cinematic 3D only where it elevates the story.
5. Use 4K imagery with careful compression and motionographic treatment.
6. Ship production code that is performant, accessible, and reduced-motion aware.

## Anti-patterns

- AI-default themes, fonts, or soft pastel cards
- Bounce > 0.2 or linear timing on interactive UI
- Competing motion or heavy post-processing that reduces clarity
- Low-resolution or synthetic imagery
- Inventing shaders when 21st.dev already provides strong ones
- Pure #000 / pure #FFF without surface nuance
