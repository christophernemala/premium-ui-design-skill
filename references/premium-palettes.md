# Luxurious Premium Colour Systems

## Linear-inspired (default SaaS / product)
- Canvas: #010102
- Surfaces: #0F1011 → #191A1B
- Hairlines: #23252A / #34343A
- Accent: #5E6AD2 (lavender)
- Text: #F7F8F8 / muted #8A8F98

## Stripe-inspired
- Deep background + indigo #635BFF accent

## Vercel / modern dark
- #0A0A0A + blue or pure white highlights

## Luxury / cinematic / serene
- Near-black #09090B
- Champagne / soft gold #E8D5B7 / #D97706
- Controlled metallic and liquid-metal accents via shaders

## Rules
- One primary accent + optional metallic secondary
- High contrast text
- OKLCH tokens preferred
- Hairlines and surface ladders over heavy shadows
- Soft off-white (#FAFAFA / #F8F7F4) for light mode
- Serene = restrained chroma, deep values, precise accents
